## Question 1

What is indentation in Python, and why is it important?

## Answer

Indentation means the spaces or tabs at the beginning of a line of Python code. Python uses indentation to define a block of code.

Unlike languages such as C or Java, Python does not use `{ }` to define blocks of code.

### Example

```
if age >= 18:    print("You are an adult")    print("You can vote")
```
