# Question 5

What is a lambda function? When is it useful?

## Answer

A lambda function in Python is a small anonymous function defined using the `lambda` keyword. It can take any number of arguments but contains only one expression.

## Syntax

```python
lambda arguments: expression
```

## Example

```python
square = lambda x: x * x
print(square(5))
```

**Output:**

```text
25
```
